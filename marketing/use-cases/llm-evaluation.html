NanoLambda for LLM Evaluation

Run thousands of AI-generated code samples safely to evaluate model quality.

The Problem

Evaluating code-generating LLMs means running the code they produce. Benchmarks like HumanEval, MBPP, and SWE-Bench require executing thousands of test cases. Each one is untrusted. Each one needs isolation. Each one needs to be fast.

Why NanoLambda for Eval

Throughput at Scale

Process pool with warm starts means you can run 10,000+ eval samples in minutes, not hours. Sub-millisecond warm starts eliminate the bottleneck.

Safe by Default

Every code sample runs in its own sandbox with memory limits, network isolation, and filesystem confinement. A malicious model output cannot affect other evaluations or your infrastructure.

Simple Integration

from nanolambda import NanoLambda

sandbox = NanoLambda(api_key="nl_...")

# Run each eval sample
for sample in eval_dataset:
    result = sandbox.execute_python(
        sample.generated_code,
        timeout_ms=10000
    )
    sample.passed = result.exit_code == 0
    sample.output = result.stdout
