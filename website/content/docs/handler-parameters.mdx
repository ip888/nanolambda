# Handler Parameters

Every NanoLambda function receives two parameters: `event` and `context`.

## Function Signature

### Python
```python
def handler(event, context):
    # Your code here
    return {"result": "success"}
```

### Node.js
```javascript
exports.handler = async (event, context) => {
    // Your code here
    return { result: "success" };
};
```

### Java
```java
public class Handler {
    public Map<String, Object> handler(Map<String, Object> event, Context context) {
        // Your code here
        return Map.of("result", "success");
    }
}
```

---

## Event Parameter

The `event` parameter contains the input data sent when invoking your function.

### Example Event

When you invoke:
```bash
curl -X POST http://localhost:8080/functions/my-func/invoke \
  -d '{"name": "Alice", "age": 30}'
```

Your function receives:
```python
{
    "name": "Alice",
    "age": 30
}
```

### Accessing Event Data

**Python:**
```python
def handler(event, context):
    name = event.get("name", "World")
    age = event.get("age", 0)
    return {"greeting": f"Hello {name}, age {age}!"}
```

**Node.js:**
```javascript
exports.handler = async (event) => {
    const name = event.name || "World";
    const age = event.age || 0;
    return { greeting: `Hello ${name}, age ${age}!` };
};
```

## Context Parameter

The `context` parameter provides information about the execution environment.

### Context Properties

```python
{
    "function_name": "my-function",      # Name of the function
    "memory_limit_mb": 128,              # Memory limit
    "timeout_seconds": 30,               # Timeout setting
    "request_id": "req_abc123",          # Unique request ID
    "remaining_time_ms": 29500           # Time left before timeout
}
```

### Using Context

**Python:**
```python
def handler(event, context):
    print(f"Function: {context['function_name']}")
    print(f"Memory limit: {context['memory_limit_mb']}MB")
    print(f"Time remaining: {context['remaining_time_ms']}ms")
    
    return {
        "processed_by": context['function_name'],
        "request_id": context['request_id']
    }
```

**Node.js:**
```javascript
exports.handler = async (event, context) => {
    console.log(`Function: ${context.function_name}`);
    console.log(`Memory limit: ${context.memory_limit_mb}MB`);
    console.log(`Time remaining: ${context.remaining_time_ms}ms`);
    
    return {
        processed_by: context.function_name,
        request_id: context.request_id
    };
};
```

## Real-World Examples

### 1. API Endpoint

```python
def handler(event, context):
    """REST API endpoint handler"""
    method = event.get("method", "GET")
    path = event.get("path", "/")
    body = event.get("body", {})
    
    if method == "GET":
        return {"status": 200, "data": get_data()}
    elif method == "POST":
        return {"status": 201, "data": create_data(body)}
    else:
        return {"status": 405, "error": "Method not allowed"}
```

### 2. Data Processing

```python
def handler(event, context):
    """Process uploaded data"""
    data = event.get("data", [])
    
    # Check if we have enough time
    if context["remaining_time_ms"] < 5000:
        return {"error": "Not enough time to process"}
    
    # Process data
    processed = [item * 2 for item in data]
    
    return {
        "processed_count": len(processed),
        "results": processed,
        "execution_time": 30000 - context["remaining_time_ms"]
    }
```

### 3. Webhook Handler

```javascript
exports.handler = async (event, context) => {
    const { webhook_type, payload } = event;
    
    console.log(`[${context.request_id}] Processing ${webhook_type} webhook`);
    
    switch (webhook_type) {
        case "github.push":
            return handleGitHubPush(payload);
        case "stripe.payment":
            return handleStripePayment(payload);
        default:
            return { error: "Unknown webhook type" };
    }
};
```

### 4. Scheduled Job

```python
def handler(event, context):
    """Runs on schedule (e.g., every hour)"""
    trigger_time = event.get("trigger_time")
    
    print(f"[{context['request_id']}] Job started at {trigger_time}")
    
    # Cleanup old data
    deleted = cleanup_old_records()
    
    # Send notification
    notify_admin(f"Cleanup complete: {deleted} records deleted")
    
    return {
        "status": "success",
        "records_deleted": deleted,
        "next_run": calculate_next_run()
    }
```

## When to Use Context

### ✅ Use Context When:

- **Logging:** Include request ID for tracing
- **Monitoring:** Track execution time and memory
- **Timeouts:** Check remaining time for long operations
- **Debugging:** Identify which function version is running
- **Metadata:** Return function info to caller

### ❌ Don't Need Context When:

- **Simple functions:** Just transform input to output
- **Stateless operations:** No side effects or monitoring needed
- **Quick computations:** Timeout isn't a concern

## AWS Lambda Compatibility

NanoLambda's `(event, context)` pattern matches AWS Lambda for easy migration:

**AWS Lambda:**
```python
def lambda_handler(event, context):
    return {"statusCode": 200, "body": "Hello"}
```

**NanoLambda:**
```python
def handler(event, context):
    return {"statusCode": 200, "body": "Hello"}
```

Just change the function name and you're done! 🎉

## Common Patterns

### Return Success Response
```python
def handler(event, context):
    result = process_data(event)
    return {
        "success": True,
        "data": result,
        "request_id": context["request_id"]
    }
```

### Handle Errors
```python
def handler(event, context):
    try:
        result = risky_operation(event)
        return {"success": True, "data": result}
    except Exception as e:
        return {
            "success": False,
            "error": str(e),
            "request_id": context["request_id"]
        }
```

### Timeout Protection
```python
def handler(event, context):
    items = event.get("items", [])
    processed = []
    
    for item in items:
        # Check if we have time left
        if context["remaining_time_ms"] < 1000:
            break
        
        processed.append(process_item(item))
    
    return {
        "processed": len(processed),
        "total": len(items),
        "completed": len(processed) == len(items)
    }
```
