Security

Defense in depth for every execution.

Process isolation

Each execution runs in its own isolated process with seccomp filters.

Memory limits

Hard cgroup limits prevent runaway allocations from affecting other tenants.

Network isolation

Sandboxes have no network access by default. Opt-in allowlists available.

Filesystem sandboxing

Read-only root filesystem. Writable tmpfs only within the sandbox scope.

Non-root execution

All user code runs as an unprivileged user with minimal capabilities.
